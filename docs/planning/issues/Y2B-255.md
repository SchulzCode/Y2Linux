## Exact implementation scope after the gate

1. Reuse proven MUSB in **peripheral-only PIO mode** with built-in `g_serial`,
   defaults ACM on / OBEX off / one port. Kernel intent:
   `USB_SUPPORT=y`, `USB_GADGET=y`, `USB_MUSB_HDRC=y`, `USB_MUSB_GADGET=y`,
   `MUSB_PIO_ONLY=y`, `USB_G_SERIAL=y`; host `USB=n`, DMA/OTG/dual-role off.
   `USB_MUSB_MEDIATEK` and `NOP_USB_XCEIV` apply only if the exact glue is verified;
   selected GENERIC_PHY/USB_ROLE_SWITCH and the real provider must be accounted
   for. `U_SERIAL_CONSOLE=n`; no `console=ttyGS0` dependency. Existing PRINTK/TTY/
   proc/sysfs/time32 stay enabled. g_serial selects LIBCOMPOSITE/CONFIGFS_FS and
   serial functions; no configfs mount or setup daemon is needed.
2. DT: only the reviewed USB/PHY/clock/supply nodes, `dr_mode="peripheral"`.
   Extend the exact DT validator whitelist, not D08 bounds. No guessed addresses,
   dummy PHY, fake fixed clocks, unrelated clock gating or full-SoC DTS import.
3. Existing native PID1: bounded raw nonblocking `/dev/ttyGS0` relay. Discover
   its dynamic device number from sysfs; read kernel ring through `/dev/kmsg`
   (1:11, read-only). Keep an 8 KiB PID1 startup/status ring, 32 KiB TX queue,
   8 KiB kernel-record buffer. Service at most 16 records / 16 KiB each heartbeat
   pass. Preserve partial writes and report drops/gaps; boot/heartbeat never
   waits for a host. New syscall numbers require actual linked-kernel checks.
4. Host sends only `LOG1\n` to begin/restart replay of retained kernel and PID1
   startup records, then live records/status. Bounded 16-byte parser; no shell,
   arbitrary command execution or writable filesystem/log API. Include kernel
   release, build identifier, source/sequence and explicit overflow markers.
5. Host script selects an explicit verified USB tty path, commonly `/dev/ttyACM0`
   but never inferred from numbering alone. Raw 115200 8N1/no flow control, ACM
   DTR asserted, sends LOG1, records bytes/timestamps/USB identity and exit reason.
   Use upstream standard g_serial descriptors, not stock Android VID/PID. Read
   `/sys/class/tty` USB parent identity; no privileged global host-rule changes.
