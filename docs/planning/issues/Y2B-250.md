# Y2B-250 — Restore ARM time32 nanosleep for the diagnostic heartbeat

Depends on [Y2B-245 #20](https://github.com/SchulzCode/Y2Linux/issues/20).
Owner hardware evidence: renderer, PID1, proc/sysfs mounts work; first sleep
returns -38 (ENOSYS), ending at `BEAT: 0 / STOP: SLEEP ERROR`.

Linux v6.18 ARM syscall 162 maps to `sys_nanosleep_time32`, compiled only with
`CONFIG_COMPAT_32BIT_TIME`. The tested allnoconfig output disables it; the linked
symbol is a weak alias to `sys_ni_syscall`. Enable only that config option.
`CONFIG_POSIX_TIMERS` is not the dependency and remains disabled.
